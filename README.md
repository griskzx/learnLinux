## 实验习惯

内核模块实验建议在可恢复快照的虚拟机中进行。每次实验记录内核版本、编译步骤、预期行为、实际日志和结论，使用与实验内核匹配的构建环境。

不要将完整内核源码、编译产物或虚拟机镜像提交到本仓库。
