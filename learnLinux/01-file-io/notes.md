# 01 观察

先写预测，再跑程序。跑完把实际结果补在同一题下面。

## 1. 读代码

`open` 的三个参数分别是什么？`sizeof text - 1` 少掉的那一个字节是什么？

## 2. 运行

`./file_io` 打印了什么？`cat sample.txt` 的内容和打印是否一致？

## 3. strace

从 `trace.txt` 贴出写文件的那次 `openat`、对应的 `write`、读文件的那次 `openat`、对应的 `read`，以及两次 `close`。

每次系统调用末尾的返回值是什么？两次 `openat` 返回的 `fd` 各是几？

## 4. 和 F439 对照

用自己的话写：文件描述符和 Flash 地址（例如 `0x0802_0000`）有什么不同？谁持有真正的磁盘位置？

## 5. 改一行再验证

先预测：删掉 `O_TRUNC`，不删除 `sample.txt`，再运行两次，文件内容会变成什么？

然后改 `file_io.c`，`make` 之后运行两次，把 `cat sample.txt` 的结果写在这里。预测和结果不一致的话，写出差在哪。
